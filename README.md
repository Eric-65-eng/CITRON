Citron est un lecteur multimédia « tout-en-un » : il lit vos films, séries et musiques stockés sur votre ordinateur, peut les envoyer sur votre téléviseur, télécharger des vidéos depuis Internet, enregistrer votre écran, et afficher des fiches d'information (résumé, casting, année…) pour chaque titre si vous disposez d'un tableur au format .osd (LibreOffice) contenant ces informations. Tout se pilote depuis une seule fenêtre.
